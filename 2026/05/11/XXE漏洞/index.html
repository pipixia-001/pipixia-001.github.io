# XXE外部实体注入漏洞

一、XXE简述以及XML语言简介

  • 1.1 XML，可扩展标记语言，是一种标记语言，使用简单标记描述数据

  • 1.2 XML是一种=非常灵活的语言。，没有固定的标签，所有标签都可以自定义

  • 1.3 通常，XML被用于信息的传递和记录，因此,XML经常被用于充当配置文件

  • 1.4 HTML旨在显示数据的信息，而XML旨在用来进行数据的传输和储存

  • 1.5 XML文档格式：

    • 1.5.1 文档结构：

      • XML声明
      • DTD-文档类型定义（可选）
      • 文档元素

    • 1.5.2 XML文档树结构

        1. XML文档形成了一种树结构，从根部开始，然后拓展
        2. 父、子以及同胞等术语用于描述元素之间的关系。父元素拥有子元素，相同层级上的子元素称为同胞
        3. 所有的元素都可以有文本内容和属性

二、实体

Entities

  • 2.1 实体：实体是对数据的有引用，根据实体的种类不同，XML解析器将使用实体的替代文本或者外部文档的内容来替代实体引用。理解为一种变量，或者说实体为一种包裹，数据为包裹里面的物品，当我们引用这个包时，就是拿了里面的数据

  • 2.2 实体的分类：

      1. 字符实体
      2. 普通实体
      3. 参数实体
      4. 内部实体
